Why Crate

One click to extract
The mini view opens on double-click with one big Extract button and live progress.
Safe by default
Blocks path-traversal and symlink escapes, warns on decompression bombs, never rewrites the original until the new copy is complete.
Readable names, any language
Fixes garbled Arabic, Japanese and Cyrillic names in old ZIPs. Full Arabic, right-to-left interface.
All the formats
ZIP, 7z, tar.zst / gz / xz / bz2 to read and write. RAR and ISO to read.
Feels native everywhere
Proper title bars on each OS, light and dark themes, drag in and out, quick preview with Space.
Scriptable
crate x photos.zip uses the same Rust core from the terminal.
